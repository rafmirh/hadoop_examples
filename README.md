# hadoop_examples
Hadoop examples for Herramientas Avanzadas para el Manejo de Grandes Volumenes de datos course teaching at UNRC

## Prerequisitos
Tener instalado Docker Desktop

## Ejemplos de MapReduces  
Se crea en este repositorio distintas ramas de `main` para cada ejercicio de MapReduce

### Contar palabras de un libro
Ejercicio en el cual se cuentan las palabras contenidas en un libro con formato .txt el cual puede ser consultado en la rama [tarea-2](https://github.com/rafmirh/hadoop_examples/blob/tarea-2/README.md) 

### Solución de un Sudoku
Ejercicio en el cual se resuelve un Sudoku el cual puede ser consultado en la rama [tarea-3](https://github.com/rafmirh/hadoop_examples/blob/tarea-3/README.md) 

## Referencias
Tomamos la estructura de **docker-hadoop** de [https://github.com/big-data-europe/docker-hadoop](https://github.com/big-data-europe/docker-hadoop)
